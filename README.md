# Конструктор графов

## Запуск программы

`cargo build` - сборка проекта

`cargo run -- info -f example.json` - просмотр информации о графе

`cargo run -- analyze -f example.json -s start -e end -d 50 --format dot -o result.dot` - анализ графа с экспортом в DOT

`cargo run -- analyze -f example.json -s start -e end -d 50 --format mermaid -o result.txt` - анализ графа с Marmaid

`cargo run -- --help` - справка

`cargo run -- analyze --help` - справка о команде
